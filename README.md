# Cocktails — Cocktail Search Application

Командный frontend-проект — веб-приложение для поиска и просмотра коктейлей.

Приложение получает данные из внешнего API, позволяет искать коктейли, просматривать карточки и рецепты, добавлять понравившиеся позиции в избранное и удобно работать с каталогом на разных устройствах.

## Live Demo

https://solusblade.github.io/ITD-js-project/

## О проекте

Cocktails разработан командой в рамках практической командной разработки.

Проект выполнен на Vanilla JavaScript без frontend-фреймворков и включает работу с внешним API, динамический рендер интерфейса, адаптивную пагинацию, локальное хранение данных и модальные окна.

## Основные возможности

- поиск коктейлей по названию;
- поиск по первой букве;
- получение данных из внешнего API;
- отображение случайных коктейлей;
- динамическое создание карточек;
- просмотр информации о коктейле;
- просмотр ингредиентов;
- добавление коктейлей в избранное;
- хранение пользовательских данных в браузере;
- адаптивная пагинация;
- обработка ситуации, когда поиск не дал результатов;
- светлая и тёмная тема;
- мобильное меню;
- адаптивный интерфейс;
- кнопка плавного возврата наверх.

## Локальный запуск

Установите зависимости:

```bash
npm install
```

Запустите development-сервер:

```bash
npm start
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:1234
```

## Production build

Для создания production-сборки:

```bash
npm run build
```
